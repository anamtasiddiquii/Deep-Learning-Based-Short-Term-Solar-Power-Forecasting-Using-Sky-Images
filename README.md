# Deep-Learning-Based-Short-Term-Solar-Power-Forecasting-Using-Sky-Images

[Dataset](https://www.sciencedirect.com/science/article/pii/S0038092X23002037?via%3Dihub)|[Benchmark Dataset](https://purl.stanford.edu/dj417rh1007)| [Raw Dataset](https://purl.stanford.edu/sm043zf7254)

A deep learning project for predicting near-future photovoltaic (PV) power generation using historical solar power measurements and sky images.

<img width="1564" height="626" alt="image" src="https://github.com/user-attachments/assets/7ca91a23-2e90-4aa3-a80f-26b2485d9355" />
The project aims to predict near-future solar power generation by learning relationships between sky conditions, cloud patterns, and historical PV power output. This can help improve solar energy management, forecasting, and grid integration.

📌 Project Overview

Solar power generation is highly dependent on weather and cloud conditions. Sky images provide useful visual information about cloud movement and solar irradiance conditions, while historical PV measurements provide information about previous generation patterns.

This project combines these data sources with deep learning techniques to forecast short-term PV power generation.

📊 Dataset

The project uses a benchmark dataset containing:

Sky images
Historical photovoltaic power measurements
Time-series solar power data
Corresponding image and power-generation information

🚀 Features
Short-term photovoltaic power forecasting
Sky-image-based weather feature extraction
Historical PV power analysis
Image preprocessing using OpenCV
Data analysis and visualization
Deep learning model development using TensorFlow
Evaluation of forecasting performance
